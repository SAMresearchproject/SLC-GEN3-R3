# SLC-GEN3-R3 computational source

The public entry point is `python -m slc_gen3_r3`.
See [usage](../../../docs/USAGE.md), [distribution scope](../../../docs/DISTRIBUTION_SCOPE.md)
and the [retained upstream installation description](../../../docs/upstream/GEN3_R3_INSTALLED_README.md).

`gen3_runtime.py` is the selected runtime. `gen2_runtime.py`, `gen2/`, `native/`
and the Q3 foundation are bound inherited components. `gen3/` contains unified
execution, acquired memories, exact logarithmic accounts and durable local storage.
