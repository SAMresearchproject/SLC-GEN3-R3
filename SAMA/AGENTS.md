# SAM volumes — contributor instructions

Organize the public research as Volume I, Volume II, Volume III and Volume IV.
Put branches inside their volume and related tests in each branch’s `tests/`
folder. Write introductions for readers learning SAM; introduce technical terms
before relying on them. Keep shared methods under `methodology/`.

Preserve source identities, mathematical statements, recorded results, failures
and corrections. Keep cross-volume references explicit. Sean Brady remains the
approval authority; structural changes do not approve scientific records.

Retain the existing public licences and disclosure boundary. Publish only
material already authorized for the public repository. Before publication,
run `python3 tools/check_structure.py` and inspect the exact changed-file roster.
Do not restore the atlas navigation framework as the primary reading structure.
