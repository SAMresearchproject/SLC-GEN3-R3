# CR214 CR119 Particle Complement Pattern Audit

## Task

Identify the 195 CR119 particle rows outside the 126-row matter table and test
whether their complement structure carries a data-backed pattern.

## Classification

This is a Courtroom readout audit over the already sealed CR119 and LC04 table
surfaces. It does not re-grade CR119. It computes the complement implied by the
tables and records the observed categories.

## Inputs

- CR119 courtroom particle table
- CR119 courtroom matter table
- CR119 courtroom periodic table
- CR119 latest export summary and counts
- LC04 particle replay layers
- LC04 generator suite register

## Pass Conditions

- Particle table has 321 rows.
- Matter table has 126 rows.
- Periodic table has 126 rows and remains a separate element-family layer.
- Matter table candidate ids are a subset of particle candidate ids.
- Particle-minus-matter complement has 195 rows.
- Complement rows are exported with their original CR119 row fields and a
  complement readout.
- Matter-gate rejection reasons account for all 321 particle rows.
- Pattern leads distinguish backed row facts from open count coincidences.

## Non-Promotion Rule

Observed count matches are not promoted to mechanism. CR214 may record them only
as follow-up leads unless a row-level mapping exists in the input tables.
