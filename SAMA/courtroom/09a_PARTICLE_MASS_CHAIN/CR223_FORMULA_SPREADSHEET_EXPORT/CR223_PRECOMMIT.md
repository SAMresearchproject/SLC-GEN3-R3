# CR223 Precommit - Formula Spreadsheet Export

## Task

Create an Excel workbook that calculates the constants-only element generator
with formulas.

## Workbook Requirements

- Constants sheet with editable SAM constants and formula-derived kernel terms.
- Shells sheet deriving `[2,8,18,32,32,18,8,8]` from the shell path.
- Elements sheet with 126 formula rows for `Z`, `N`, `P`, quark address,
  shell placement, `G(P)`, `GR(P)`, and retained support.
- Isotope candidate sheet with 252 formula rows and an active-ladder count of
  214.
- Checks sheet with formula-based row counts and key readouts.

## Boundary

The workbook must not use element cards, known symbols, known names, measured
masses, or CLOCK labels as construction inputs. CR222 may be used as a
verification source for the expected outputs.
