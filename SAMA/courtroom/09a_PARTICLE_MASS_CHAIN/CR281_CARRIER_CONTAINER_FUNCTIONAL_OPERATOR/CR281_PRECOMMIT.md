## Precommitted Operator

Constants and atoms use exact integer arithmetic:

```text
h = 2
d = 3
S = h^3 = 8
R = h^2*d = 12
Theta = h*d^2 = 18
M = (S - 1)*Theta = 126
R^2 = S*Theta = 144
L = h*d^4 = R^2*d^2/S = 162
```

Each tested atom is represented by a source-supported exponent address
`A = h^a*d^b` and by source structural seating:

```text
traffic = between-mirror flake traffic
boundary = mirror surface / container / radix-volume-face seating
ledger = closed total ledger
```

Define the carrier-container functional operator `F_cc(A)`:

```text
F_cc(A) =
  TERMINAL_CLOSURE
    iff A = L = h*d^4 = R^2*d^2/S.

  FIXED_POINT
    iff A is boundary-seated:
      (a,b) = (2,1)              [R, radix / closure radius]
      OR
      a = 0 and b >= 3           [pure d^k volumetric boundary: V, F].

  OUTPUT
    iff A is released traffic and not terminal:
      a = 1 and 1 <= b <= 3      [h*d, h*d^2, h*d^3]
      OR
      (a,b) = (0,2)              [D^2 closure-witness / axis-fee output].

  OUT_OF_TARGET_DOMAIN otherwise.
```

This rule does not use isotope stability, abundance, half-life, observed
decay mode, or prior stable/unstable target labels. It uses only exact
source arithmetic, exponent address, bow release, mirror-surface seating,
and ledger closure.

Why 18 is no-lift/no-fee:

```text
18 = Theta = h*d^2 = R^2/S.
It is the single released copy in B: R^2 -> (M, Theta_out), not a seated
local matter row. CR233 gives M_rest(Theta)=18-18=0, and Volume II records
that L_18=20.25 appears in no row because charging Theta a local fee breaks
L=162. Under F_cc, 18 is OUTPUT because it is released traffic, not
boundary-seated and not terminal.
```
