# CR223c_HF High-Fidelity Simulator Contact

Re-runs the sealed CR223c pipeline against a noise-augmented NV qutrit simulator across three platform regimes. Validates that the analysis survives realistic SPAM, readout confusion, pulse fidelity error, 1/f phase noise, and rate drift.

Run: `pip install -r requirements.txt && python CR223c_HF_runner.py`
