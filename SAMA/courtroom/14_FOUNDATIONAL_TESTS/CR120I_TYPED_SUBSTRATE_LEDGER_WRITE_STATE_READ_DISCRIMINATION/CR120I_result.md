## Constructed write-state-read result

```text
W(S,u) = (S + Pi80*u, tag_K((I-Pi80)*u))
R(S,p_i) = coordinate i of S

```

Every frozen write closes that accounting exactly. The writer action, input,

## What the candidate discriminates

- `u=e1` and `u=e2` produce different written states with the same zero
  residue.
- `u=e1` and `u=e0+e1` produce the same written state with different residues.
- `u=e0` produces a nonzero residue with no retained record.

Therefore residue is neither the record nor a complete determinant of the
record.

Histories `[e1,e2]` and `[e2,e2]` end with the same input `e2` but produce
different full snapshots. The state therefore retains information unavailable
to a terminal-input-only control. Sixteen identity-delay steps preserve the
record exactly.

Histories `[e1,e2]` and `[e2,e1]` produce the same snapshot. This additive
candidate stores the complete current frame, not a complete ordered transcript
of every prior frame. The "film" is the update sequence; one frame is not the
whole reel.

## Readout and erasure

The frozen 81-coordinate probe family separates every unequal trial state. The
single-probe control `{p1}` incorrectly merges `0` and `e2`, proving that an
incomplete readout can hide a real record.

```text
exact inverse        scar distance squared 0
sham erase           scar distance squared 1
summary-only erase   scalar restored, scar distance squared 2
overwrite            distinct new snapshot e1+e2
```

The exact inverse erases perfectly in this reversible fixture. A persistent
scar is therefore not inevitable. But restoring one scalar summary is not
erasure when the full probe family still distinguishes the state.
