# Row Schema and Units

The canonical QP093A CSV supplies row identity, type, and numeric authority. Workbook columns are research-overlay occurrences.

- `M_native`, `M_observed_candidate`, `qA_source_support`, `tensor_carrier_support`, `retained_write_support`, and `S_debit_or_credit` are preserved in source ledger units.
- No conversion to MeV is made except where the source row itself labels the normalized Higgs comparison.
- `tensor_carrier_support + retained_write_support = qA_source_support` is a column-construction identity and is counted once.
- `candidate_id` identifies a QP occurrence; equal scalars do not merge QP coordinates, typed surfaces, axes, witnesses, carriers, or supports.
- Workbook formulas are reported with cached stored values; no workbook code or formulas are executed.
