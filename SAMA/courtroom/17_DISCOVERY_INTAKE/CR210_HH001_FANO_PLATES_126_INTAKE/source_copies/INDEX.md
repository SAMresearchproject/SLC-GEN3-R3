## Entry Template

```text
filename:        HH<NNN>_<SHORT_DESCRIPTIVE_NAME>.md
status:          SHADOW / EXPLORING / READING / HANDED_OFF / ARCHIVED / RETIRED
opened_at_utc:   YYYY-MM-DD
what_is_noticed: one paragraph
why_it_matters:  one paragraph
what_would_break: explicit falsifier
next_move:       explore further / propose CR / archive / retire
```

## Numbering

```text
HH001 - HH099    foundation-layer explorations
HH100 - HH199    particle / matter explorations
HH200 - HH299    gravity / horizon / cosmology explorations
HH300 - HH399    quantum / information explorations
HH400 - HH499    cross-channel readings (multi-layer)
HH500+           reserved
```

Numbering is a hint, not a contract. Cross-channel entries can be filed under
HH400 even if they touch other ranges.
