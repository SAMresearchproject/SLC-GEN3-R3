# House Rules

The exploration posture for Haunted House. These are the rules that REPLACE
Courtroom rules for this repo. Courtroom rules apply downstream when an entry
is handed off; they do not apply here.

## Posture

```text
This is exploration, not adjudication.
Patterns are followed, not pre-committed to.
Integer matches are flagged as structural readings, not dismissed as coincidence.
Wrong is allowed. Hidden is not.
```

The discipline that survives from the Courtroom:

```text
zero free parameters
no fitting to external data targets
integer / structural readings are first-class
nothing is coincidental (state the structural principle, do not hedge)
```

The discipline that is RELAXED here:

```text
no pre-reveal hash freeze required
no sealed envelope before exploration begins
no CR-class wrong-control sweep required to propose a reading
no zipper or branch verdict required to record a SHADOW
external comparisons are allowed as orientation (not as fit targets)
```

## Allowed

```text
- noticing an integer match across SAM channels and recording it as a SHADOW
- proposing a structural reading that crosses particle / gravity / quantum lanes
- following a pattern that has no obvious mechanism yet
- writing speculative entries as long as they declare status SHADOW or EXPLORING
- naming what would falsify a reading in advance (this is the entry fee)
- archiving an entry without promotion (failed exploration is success)
- retiring an entry when the structure does not hold (this is also success)
- recording an external observation as orientation (named as orientation, not fit)
```

## Required

Every entry, at minimum, must declare:

```text
status              SHADOW / EXPLORING / READING / HANDED_OFF / ARCHIVED / RETIRED
what_is_noticed     a one-paragraph statement of the structural pattern
why_it_matters      which SAM closure or open question it touches
what_would_break    the falsifier (what wrong-control or observation would kill it)
next_move           explore further / propose CR / archive / retire
```

Readings (status = READING) additionally require:

```text
load_bearing_pieces   which existing SAM closures the reading rests on
proposed_test         the CR-class test that would adjudicate it
predicted_pass        what passing looks like (without retuning)
predicted_fail        what failing looks like
forward_blind_calls   any observational predictions the reading commits to
```

If an entry cannot fill `what_would_break`, it does not become a reading. It
stays a shadow or a question. Unfalsifiable patterns are recorded but not
promoted.

## Forbidden

```text
- claiming theorem-grade status from inside Haunted House
- adding free parameters to make a pattern work
- fitting a reading to an external observation
- promoting a reading to the parent SAM repo or Courtroom without test handoff
- hiding speculation under more confident wording
- citing a Haunted House entry as Courtroom-grade evidence
- using "intentional or coincidental?" framing (state structural principle directly)
- back-dating entries (status changes get new dates, old text preserved)
```

## Status Flags

```text
SHADOW           noticed; not yet explored; entry fee = describe + falsifier
EXPLORING        actively followed; entry fee = working notes preserved
READING          structural reading proposed; entry fee = full reading template
HANDED_OFF       moved downstream (Courtroom CR / parent repo derivation)
ARCHIVED         explored and set aside without promotion (with reason)
RETIRED          reading did not hold (with reason and what falsified it)
```

A SHADOW that lingers without status update for too long is a smell. The repo
is not a graveyard for unowned patterns. Either move it forward or archive it.

## Relationship To The Courtroom

```text
Haunted House    proposes structural readings, follows patterns
Courtroom        seals, hashes, wrong-controls, verdicts
```

Promotion direction is one-way: Haunted House -> Courtroom (or parent repo).
No Courtroom CR result is ever modified by a Haunted House entry. If a
Courtroom verdict contradicts a Haunted House reading, the reading retires
or is reframed; the Courtroom verdict stands.

## Authorship Inside Haunted House

Speculative entries are allowed to be authored quickly. They are NOT allowed
to be authored without status flags and falsifier statements. The discipline
is not in slow writing; the discipline is in the entry fee:

```text
no entry without status flag
no reading without falsifier
no promotion without handoff
```

## When In Doubt

```text
If unsure whether a pattern is real -> SHADOW (record it, do not promote it)
If unsure whether a reading is testable -> question (move to questions/)
If unsure whether to keep an entry -> archive (with reason)
```

The cost of recording a wrong pattern is small. The cost of promoting a wrong
pattern is large. House rules optimize for the first cost, not the second.
