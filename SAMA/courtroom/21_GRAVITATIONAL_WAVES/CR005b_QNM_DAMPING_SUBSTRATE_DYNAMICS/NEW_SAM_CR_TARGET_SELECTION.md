## Selection

Selected target: candidate 1, CR005b damping-shell derivation.

Selection reasons:

- Scientific leverage: it extends the branch 21 carrier-tensor program from
  real-frequency propagation into damping/loss, the next explicitly opened
  QNM frontier.
- Source readiness: CR003, CR004, CR005, and the QNM study notes provide a
  complete source chain and state exactly what remains open.
- Falsifiability: the run can fail exact source identities, fail the external
  Berti comparator threshold, or fail wrong-control separation.
- Bounded implementation: exact integer/rational arithmetic, one comparator,
  finite wrong controls, no arbitrary fitted constant.
- Independence from language firewall: the question is worth running as
  ordinary SAM gravitational-wave physics.

Not selected:

- PMNS mixing was deferred because the source chain records the boundary but
  does not yet provide a tight operator path.
- The theta-star discrepancy was deferred because it is closer to an audit of
  an existing precision result than a clean new constructive CR.
- Full electroweak closure was deferred because its theorem scope is too large
  for one bounded new CR.
- Detection-rate sanity was deferred because it needs external rate modeling
  and risks hidden population parameters.
