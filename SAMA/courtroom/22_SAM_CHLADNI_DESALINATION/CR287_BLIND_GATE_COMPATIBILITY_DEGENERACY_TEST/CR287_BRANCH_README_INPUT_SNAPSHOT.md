# 22 - SAM Chladni Desalination

This branch is an open-source-water track for SAM-inspired desalination tests.

It uses Courtroom discipline where it helps:

- falsifiers before claims;
- wrong controls;
- energy-normalized metrics;
- public literature and engineering references allowed under campaign-specific
  reveal rules.

The branch began with `SCD-01`, a SAM-Chladni Acoustic Electrodialysis /
Crystallization test plan, and `SCD-02`, a helper-field simulator. That
acoustic lane is preserved as historical work but shelved by
`ACOUSTIC_LANE_SHELF_RECORD.md` after the later shape results supplied a
cleaner passive-membrane direction.

The formal Courtroom campaign begins with `CR284`, which freezes a second,
independent opportunity lane before any water-ion reference table is used as a
fit target:

```text
QP093A shape grammar
-> water / hydration-shell construction
-> pore compatibility
-> deformation or de-coordination cost ordering
-> blind comparison with ordinary molecular baselines
```

CR284 is an intake and source-contract gate. It is not a membrane result,
physical desalination evidence, or a claim that SAM carriers are dissolved
ions.
