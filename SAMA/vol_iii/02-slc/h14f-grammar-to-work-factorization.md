## Conceptual abstract

The central Volume III computational finding is not that a \(2^{100}\) state
space disappeared. It is that the source-derived N100 grammar carries an exact
factorization certificate. The unchanged 100-spin Hamiltonian has eight
conditional components. Evaluating those components locally and convolving
their exact tensors reconstructs the same complete result as the H14F
variable-elimination route, coefficient for coefficient.

This separates three quantities that are often confused:

```text
formal state space       = every one of 2^100 assignments counted
requested exact output  = the complete retained-role DOS tensor
fresh local work        = 165,920 component assignments
```

The source grammar determines the first two. A certified execution route
changes only the third. H14F remains the exact fallback when a component,
orbit, fiber, separator or rank certificate is absent or fails an installation
gate. H14F's fourteen-worker surface is a frozen execution contract where
declared, not an informal knob that can be reinterpreted as an arbitrary host
setting.

The controls make the result transferable. N105 restores the excluded source
packet; N81 supplies a source-native octahedral comparison; N72 remains a dense
contrast; mixed partial-join and connected-ring graphs test whether the router
can preserve exactness when components are coupled; N96 demonstrates exact
cutset branching and fallback. These controls show what the router is: a
typed grammar-to-work compiler, not a rule that substitutes the N100 graph for
other systems.

Historically, H14F and the structure-first receipts belong to the exact
arithmetic/application lineage now preserved in the delegated frozen
`SLCV21R` base. Frozen `SLCQ2-RZ` is the sole current/default SLC selection
engine. Q2 consumes the byte-identical base services; it does not turn H14F
into the present ordinal selector or erase the earlier exact results.

## 1. Opening question and conceptual picture

The governing question is:

> When a finite grammar defines a complete exact calculation, can the grammar
> itself certify a smaller execution plan without changing the mathematical
> state space, Hamiltonian or requested output?

The answer is represented by

```text
typed source grammar
  -> declared Hamiltonian and requested tensor
  -> structural certificate discovery
  -> admitted exact route
       component convolution
       orbit-sector counting
       separator branching
       rank-aware readout
       or H14F exact fallback
  -> independent reconstruction of the same tensor
```

The router never asks which route would make a preferred outcome appear. It
asks which exact decomposition is already present in the declared object. If
the certificate is missing, the object is not modified to create one.

## 2. Typed definitions and execution contract

### 2.1 Mathematical object versus execution profile

For a fixed Hamiltonian \(H\), define the retained-role tensor

\[
G(e,r)=\#\{\sigma:H(\sigma)=e,\ R(\sigma)=r\},
\]

where \(r\) is one of the declared port-role states. Its scalar DOS is

\[
g(e)=\sum_rG(e,r).
\]

The mathematical object consists of \(H\), the assignment domain, the role
map \(R\), and every requested coefficient \(G(e,r)\). H14C and H14F specify
how that object is evaluated. They may change elimination order, batching,
residue storage, worker persistence and cache policy. They may not change
\(H\), delete assignments, reinterpret the roles or replace \(G\) with a
smaller target.

### 2.2 H14C and H14F

H14C is the completed fourteen-core profile with complete-prime calibration
and the accepted retained-capacity contract. H14F adds mixed-width
compilation, persistent workers, reduced residue storage and an ephemeral
scale-specific projection cache. Both are exact execution profiles.

Where an H14F campaign declares fourteen pinned physical workers, that width
is part of the frozen architecture. It cannot silently become “whatever
number of host workers is available,” because batching, custody and timing
receipts are indexed to the declared worker surface. A new worker mapping
would be a successor execution profile, not a reinterpretation of the old
one.

### 2.3 Structural certificate

A structural certificate is exact evidence that the requested object can be
reconstructed from smaller typed objects. Examples include:

- disconnected components after an explicit conditioning boundary;
- a permutation orbit on which energy depends only on marked population;
- a cutset whose fixed assignments reduce admitted elimination width;
- a fee-exempt fiber whose multiplicity can be lifted exactly; and
- a constrained readout with a known independent rank.

The certificate must contain the reconstruction rule. A low-width-looking
plot or favorable runtime is not enough.

### 2.4 Router and fallback

The routing policy is

```text
if conditional components close:
    evaluate each component exactly and convolve
elif uniform orbit sectors close:
    count exact marked-population sectors
elif a declared cutset lowers admitted width:
    branch exactly on every cutset assignment
elif the output is a constrained fiber/readout:
    evaluate independent rank and reconstruct the ambient view
else:
    execute the exact H14F variable-elimination fallback
```

Every branch returns the complete requested tensor. Failure to certify one
branch is a routing outcome, not permission to approximate.

H14F treats the complete 100-spin, 260-edge Hamiltonian as one retained-port

### 3.2 Retained-role closure

\[
\sum_{r=0}^{15}\sum_eG(e,r)
=16\cdot2^{96}
=2^{100}.

The scalar result has 177 occupied energy bins and ground sector

Thus counts 0/4 share one spectrum, 1/3 share a second and 2 supplies the

## 4. Deriving the N100 structure-first work

### 4.1 Component census

The unchanged conditional grammar separates into eight exact components of
sizes

\[
15,15,15,15,15,10,10,5.
\]

The sizes sum to the original independent rank:

\[
5\cdot15+2\cdot10+5=75+20+5=100.
\]

For a component of \(n_a\) binary variables, direct local enumeration requires
\(2^{n_a}\) assignments. Therefore the total fresh component work is

\[
W_{100}=5\cdot2^{15}+2\cdot2^{10}+2^5.
\]

Evaluating each term,

\[
5\cdot32{,}768=163{,}840,
\]

\[
2\cdot1{,}024=2{,}048,
\]

and

\[
W_{100}=163{,}840+2{,}048+32=165{,}920.
\]

### 4.2 Why 165,920 does not replace \(2^{100}\)

Let component \(a\) return its exact conditional polynomial tensor
\(P_a(z,r_a)\). The full tensor is reconstructed by summing compatible role
assignments and convolving energies:

\[
P_{100}(z,r)
=\sum_{r_1\oplus\cdots\oplus r_8=r}
 \prod_{a=1}^8P_a(z,r_a).
\]

At \(z=1\), each local polynomial counts all local assignments, so

\[
P_{100}(1)
=\prod_{a=1}^82^{n_a}
=2^{\sum_an_a}
=2^{100}.
\]

The 165,920 number counts fresh local assignments evaluated by the algorithm.
The \(2^{100}\) number counts formal global assignments represented by the
reconstructed tensor. They answer different questions.

### 4.3 Same-output equality

The structure-first route completed in 0.500951441 seconds. Relative to the
3.828137395-second H14F route, the observed ratio is

\[
\frac{3.828137395}{0.500951441}\approx7.642.
\]

This comparison is meaningful because the retained-role tensors are
coefficientwise identical and have the same semantic hash. The route did not
change the Hamiltonian, sample states, truncate bins or request only the
ground sector.

### 4.4 Grammar-to-work identities

The work also admits exact source-grammar decompositions:

\[
W_{100}=162\cdot2^{10}+2^5
=2^5(72^2+1).
\]

Indeed,

\[
162\cdot1{,}024+32=165{,}888+32=165{,}920,
\]

and \(72^2=5{,}184=32\cdot162\). Therefore

\[
\frac{W_{100}-2^5}{2^{10}}=162,
\qquad
2^5\cdot162=72^2.
\]

The residual \(2^5\) is the formal assignment space of the surviving
five-role \(p=9,g=1\) packet. It is not X1 and not a physical closure object.
The identity interprets source grammar and workload; it does not claim that a
ledger total was inserted as an energy coefficient.

## 5. Source-native controls and deviations

### 5.1 N105 restoration control

N100 excludes the historical \(p=9,g=0\) witness packet. Restoring it produces
N105 and changes the exact work to

\[
W_{105}=166{,}912=163\cdot2^{10}.
\]

The difference is

\[
\Delta W=W_{105}-W_{100}
=166{,}912-165{,}920
=992
=2^{10}-2^5.
\]

This is a source-native perturbation: it restores an identified packet rather
than adding an arbitrary edge until timing changes. It also changes the
N100/N81 completion-path capacity from 40 to 45 rows.

### 5.2 N81 octahedral control

The N81 control has component sizes

\[
[11,10,11,10,10,11,10,8]
\]

and local work

\[
W_{81}=3\cdot2^{11}+4\cdot2^{10}+2^8
=6{,}144+4{,}096+256
=10{,}496
=2^7(81+1).
\]

Its octahedral bridge retains 48 cube embeddings in one full-octahedral orbit,
the completion path (1-8-9-12), reflected C4 gluing and 49,152 incidences.
This is a geometry/compiler control. Its possible causal relation to runtime
remains a research question rather than an installed explanation.

### 5.3 N72 dense contrast

N72 remains dense. It is not edited to reproduce N100's component structure.
This is the correct contrast because it asks whether the router recognizes
the actual source object rather than imposing one preferred decomposition on
every input.

### 5.4 Mixed-connectivity controls

The installation tournament adds two controlled deviations:

- a one-edge partial join, width 5, ground sector ((-261,128)); and
- a connected ring, width 5, ground sector ((-268,2)).

Both complete sixteen-row tensors equal an independent original-component
bridge contraction coefficient for coefficient. The partial join retains 128
component-orientation choices; the connected cyclic skeleton leaves the two
global orientations. These tests show that a changed coupling topology can be
handled exactly when its reconstruction rule is explicit.

### 5.5 Dense N96 fallback

The full N96 graph remains width 24. A frozen five-site cutset creates

\[
2^5=32
\]

exact branches, each admitted to H14F at width 22. This is neither a component
convolution nor an approximate shortcut. Every cutset assignment is retained,
and H14F performs the exact branch work. The regression ran 4,096 fresh tasks
and retained the frozen N96 numerical authority.

## 6. Failure, correction and routing discipline

The principal wrong route would be to treat N100's favorable graph as the
universal computational model. That route is rejected in stages:

```text
wrong control: substitute the N100 component graph for another grammar
  -> source identity is lost
correction: inspect the new object's own component/orbit/cutset/fiber/rank certificates
  -> choose only an admitted exact route
retest: reconstruct the complete tensor independently
  -> compare coefficientwise and replay dense regressions
fallback: if no certificate closes, retain H14F
```

The installation gates execute this logic rather than merely state it. They
record 12/12 route checks, 18/18 mixed arithmetic checks, 9/9 N18/N54 checks,
16/16 N72 checks and 20/20 N96 checks: 75/75 combined executed checks. Their
admission was for a separate owner-authorized promotion decision; the gate
campaign itself did not silently rewrite a current pointer.

A second deviation is the source-native N100-to-F81 compiler gap. N100 has
100/100 typed source keys and Shared72 has aggregate connector incidence for
72/100 rows, while CR211 exposes 162 address rows but zero elementwise QP
assignments. The missing elementwise join cannot be replaced by aggregate
counts or external labels. `G:G1@SAM-RESEARCH` preserves that partial-domain
boundary in `SAMA-D000034`; it is not a direct H14F result key for this
chapter.
