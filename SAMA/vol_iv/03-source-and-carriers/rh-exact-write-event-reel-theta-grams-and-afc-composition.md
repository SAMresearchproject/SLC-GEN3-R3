# RH Exact Write Event Reel, Theta Grams, and AFC Composition

## Conceptual abstract

The finite Weyl extremal compresses a section, while Complete Exact Write
retains an append-only event reel. Confusing them leads to a false generic
contraction claim: a positive Stieltjes pencil can have an adjacent reel ratio
larger than one. On the actual source, however, all 2,880 nonleading
coefficients across the executed 96 adjacent residuals are positive, giving
`0<Lambda_N(u)<1` on `u>0` for each executed pair. **The test result suggests
strong contact with the concept.**

## 1. Event Gram

Each unique source/target event has

\[
\Theta_e=(I-U_e)^*(I-U_e).
\]

This is the scheduler event Gram. A scalar RII control is insufficient; the
full paired event crosswalk is the retained object.

## 2. Shared-reference reel

The N144 source account has

```text
U_left63 + U_right63 + Theta18_shared
```

and composes with Exact Write as a weighted star. For an event set `E`, one
quotient reference gives

\[
\text{nodes}=1+143|E|,
\qquad
\text{rank}=143|E|,
\]

with one scalar kernel. Each event has 143 new ranks, and the full reel pulls
back through one shared scalar kernel.

## 3. W9/Theta realization

Every event difference `B_e=I-U_e` is realized by reciprocal W9 or Theta
leaves with the same `B_e^*B_e` pullback. This connects the exact event reel to
the W9P/Theta lifecycle without asserting that the finite event Gram alone
signs the completed source.
