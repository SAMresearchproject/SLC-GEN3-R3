# RH-GEN3-GROWTH-V5

Versioned RH domain package on SLC-GEN3-R4 / CEV1-R4, global generation
GEN3-BETHE1-20260917-G1. The original RH V4 routes and all predecessor records
remain. Native C++/GMP algorithms execute through the installed RH consumer;
R4 owns authenticated storage, spectral capabilities and checkpoints.

Start `./project start RH --objective "..."`. Execute operations with
`./project run SESSION --operation OP --payload FILE --purpose "..."`.
No producer, schedule or legacy service is started by installation or recovery.

## Current contract and selective knowledge

`RH_V5_CONTRACT {}` returns the target/formula contract, its SHA256, all operation
names and the21 admissible evidence IDs. The source is the original stopped
Mobius vector, with original mean plus weighted cuts. The controlling original
roster signed-growth target and the later sufficient uniform forcing-excess
hypothesis remain distinct. All uniform arithmetic hypotheses remain OPEN.
`RH_GROWTH_TARGET` also exposes this contract alongside its preserved V4 fields.

A source `context` has exactly `contract_sha256`, `scope`, `normalization`,
`original_tau`, `history`, and an original `roster` when applicable.
Normalization is `ORIGINAL_MEAN_PLUS_WEIGHTED_CUTS`. Auxiliary source calculations
use `scope: AUXILIARY_UNIFORM_BOUND`, `original_tau: null`, and no roster.
`ORIGINAL_ROSTER` requires a nonempty list of `{s,t}` original source blocks;
native arithmetic checks `original_tau=sum(2-1/s)` over that supplied roster.
The current source must belong to the roster. `history` is a nonempty object.
No auxiliary block is silently assigned a unique original roster normalization.

Names are immutable1..128-character strings. Every mathematical result retains
its input, context, dependencies, original source mapping and package identity.
Identical requests recover saved answers; altered inputs require a new name.

## Executable operations

| Operation | Required payload beyond `name` | Behavior |
|---|---|---|
| RH_RESEARCH_ADMIT | ids | Admit selected authenticated evidence bytes and original role/lineage. No fitting occurs. |
| RH_RESEARCH_EXPORT | — | Export a retained record and digest, zero native arithmetic. |
| RH_SOURCE_ADMIT | context,s,t,role | Verify original divisor recurrence, retain stopped a/b vectors, source hashes, complete energy and original projected readout. Role TRAINING, HELD_OUT, FIXTURE_ONLY or RESEARCH; whole4096 must be HELD_OUT. |
| RH_SIGNED_DIVISOR | source | Exact complete signed-divisor dual witness, maximizing function, actual smaller-source energy, full modes, signed drift/discrepancy crosses and tail. |
| RH_INTRINSIC_TRANSPORT | source | Exact resistance coordinate, flux, endpoint terms and dual attainment; retained rejected scalar law and full parity-forced transport. |
| RH_FORCING_EXCESS | source | Full signed forcing identity, E=A-Q_a/2, mean/cut terms, odd endpoint, exact candidate margins. |
| RH_FORCING_SCAN | source | Complete-prefix scan at32,512,4096 or8192; all maximum ties and rejected-constant counts. Auxiliary source scope required. |
| RH_FORCING_ADVANCE | source; optional previous | Advance original current prefix; reuse retained weighted state and evaluate only new energy admissions. Source reconstruction/kernel rebuilding are separately counted. |
| RH_CONDITIONAL_CONTINUATION | source,state; optional horizon | Exact branches from current prefix and known squarefree support, without future signs. Horizon1..6, clipped at source end; all maximum ties and signed terminal extrema. |
| RH_SCALE_ANCESTRY | source | Exact binary ancestry, signed E/R and each odd J; compare telescoping result with direct full energy. |
| RH_HYPOTHESIS_CHECK | witness,target,bound | Exact finite comparison; target FORCING_EXCESS or SIGNED_DIVISOR_DEMAND. Retain failure or finite survival without discharging a uniform premise. |
| RH_SPECTRAL_ADMIT | source; optional max_degree | Admit original unchanged vector through installed GEN3_SPECTRAL_ADMIT. |
| RH_SPECTRAL_PROFILE | parent,tau; optional controls | Existing R4 spectral log profile. Spectral tau is explicitly distinct from original_tau. |
| RH_SPECTRAL_REFINE | parent; optional controls | Existing R4 refinement; retain source, original normalization and prior modes. |
| RH_RESEARCH_FIT | witnesses; optional predecessor,lineage | Native exact regression stump on explicitly TRAINING forcing witnesses; all optimum ties retained. Successor fits retain predecessor rows. Historical fixtures and whole4096 excluded. |
| RH_RESEARCH_SELECT | model,candidates | Rank unused `{s,t}` candidates by learned excess; retain all score ties and declared-order execution choice. |

`RH_RESEARCH_STATUS {}` exposes records and process counters.
`RH_IMPLICATIONS {}` exposes hypotheses, their conditional implication records and
all finite checks. Neither accepts a payload name. Finite success never erases a
retained rejection. Conditional derivations keep their review-pending status.

Source scales are dyadic2..8192;0<=t<=s. Independent certificate, memory and work
budgets bound the operations. A native call has a180-second process timeout.
Controls for spectral profile/refinement are max_degree,max_new_modes,max_terms,
epsilon,tau,numerical as allowed by the existing R4 contract. Full factorization
and uniform RH estimates are research questions, not installed answers.

## Recovery and work accounting

Every retained domain record and cache entry is an origin object in the existing
R4 authenticated checkpoint; there is no parallel campaign database. Reopen an
RH V5 session to export/reuse results. Explicitly carry a qualified predecessor
checkpoint into a fresh V5 session when changing the domain version, preserving
its original root and bytes. Shared global generation and implementation stay fixed.

Native calls return measured elapsed nanoseconds and exact work counts; cached
calls report no new arithmetic. Incremental admissions, source reconstruction,
kernel work, branch nodes and training/scoring work are separate. The existing
spectral result retains its own precise new/reused-mode counters.

Source mapping: v5/SOURCE_MAPPING.json. Formula/hypothesis contract: v5/CONTRACT.json.
Selective evidence: v5/ADMISSION_INDEX.json. Every deployed package file is bound
by v5/MANIFEST.json and the current RH registry record.
