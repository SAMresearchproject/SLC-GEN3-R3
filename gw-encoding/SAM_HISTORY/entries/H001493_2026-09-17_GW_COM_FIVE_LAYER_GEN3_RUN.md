# First executable GW-COM five-layer GEN3 run

Sean Brady authorizes implementation and execution of the five-layer successor
after H001492's architecture. The prior state had the original interval demo
and designed interfaces, with no executable carrier-fitting/residual/information
pipeline or candidate admission gate.

The [runtime](../../GW_COM/runtime) and
[GW_COM_PIPELINE1 result](../../SAM_REVIEW/campaigns/GW_COM_PIPELINE1/RESULT.md)
now implement the full retained chain within the stated dimensionless C4 scope.
Native calls calculate the antipodal source, sampled readout, three exact
least-squares carrier fits, every predicted/signed-residual sample and exact
statistical ratios. Python compiles graphs, enumerates discrete candidates,
constructs permutations, derives diagnostic logs, compresses symbol streams and
performs independent exact checks. There is no global runtime promotion.

The contract was declared and snapshotted before execution. The source-control
profile and frame format are known; the prime message is not supplied to fits,
symbol selection, information-test selection or decoding. Both the calibration
and separate validation windows are known quiet simulator intervals. Carrier
selection takes the simplest model consistent with the held-out bounded-noise
criterion; all three predictions and signed residuals remain retained.

Clean and noisy prime cases recover `2,5,7,11,13,17`; an independent even-message
case recovers `4,6,8,10,12,14`. Each has two disjoint repeated packets and
permutation rank1/100 against99 shuffled gap orders, repeating the entire
framing/max-repetition search. The physical/model controls and statistical
criteria pass for those three cases. Clean/noisy unmodulated and drift-only
cases produce zero repeated candidates and are blocked before decoding. The
drift-only fit selects the amplitude-drift model; its residual carries no
repeated frame candidate.

**The test result suggests the concept is possible.**

The rank is conditional on exchangeable interval order with the observed gap
multiset, not an astrophysical false-alarm or intent probability. Physical
controls apply to the admitted C4/readout family. Continuous binary actuation,
chirp/precession, multiple polarizations, SI strain, a physical detector,
error-correcting-code search and higher-prime strength modulation remain future
work. The earlier interval demo and its classification are unchanged.

Execution uses current STARBREAKER / SLC-GEN3-R4 / SLC-GEN3-CEV1-R4:
37 native calls and526,742 native graph nodes, with no failed/incomplete calls.
Independent verification checks92 evidence records,60,136 exact source/residual
samples,36 least-squares normal equations and all six permutation-rank results.
Nine gate tests pass. A supplemental gate check explicitly handles incomplete
stages and missing individual control evidence, reproducing all six saved
admissions and all three decoded outputs without repeating numerical research.
Original code snapshots and outputs remain preserved.

The [evidence contract](../../GW_COM/EVIDENCE_CONTRACT.md), layer documents,
