## New templates: recovered implementation boundary

GEN3 can host a source-template construction search. The current A3D24 code,
however, packages four supplied A2 source ledgers: H1, H2, H3 and He3. A3D17
derives exact continuation packets between supplied ledgers. Neither is an
autonomous generator of further ledgers. The source construction precedent is
`ATOM3D/campaigns/ATOM3D_A2_HYDROGEN_LADDER/stages/A2H3_A2HE3/freeze_a3_pair.py`:
it assigns matter objects to N100 roles, chooses actual source edges and executes
paired reciprocal octahedral actions. Its assignments come from a frozen input.

The next implementation is to make those assignments a finite search space:
extend a retained parent ledger with candidate matter/role incidences, execute
the source connector actions, retain reciprocal closure and parent custody,
derive the resulting identity, then compile its terminal template and its
occurrence membership/action interface. The search policy is new work; merely
changing isotope counts or reusing the four-template membership table would
not implement that operation. No new-template generator has been installed
or executed in this campaign.

The four input vectors satisfy N<=2Z, as does every nonnegative combination.
There are68 reference targets outside that cone: seven already listed and61
missing from the earlier catalog. `FRONTIER.json` retains all68 and the exact
operation needed. This is an explicit construction research question.
